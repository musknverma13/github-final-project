# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to contribute and help improve this project!

---

## How to Contribute

### 1. Reporting Bugs
If you find a bug or issue while using the project:
* Check existing [Issues](../../issues) to see if it has already been reported.
* If not, open a new issue describing the bug, steps to reproduce it, and your expected outcome.

### 2. Suggesting Enhancements & Ideas
Ideas for new features or improvements are always appreciated:
* Open an issue with the title clearly describing your proposal.
* Explain why this enhancement would be useful to the project.

### 3. Improving Documentation
Fixing typos, clarifying usage instructions, or adding examples in the `README.md` or other docs is a great way to contribute:
* Fork the repository and make your changes directly.
* Submit a Pull Request describing what you updated.

### 4. Submitting Bug Fixes & Code Contributions
